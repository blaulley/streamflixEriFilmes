STREAMFLIX - PACOTE PARA GITHUB PAGES

1. Extraia este ZIP no computador.
2. Abra seu repositório no GitHub.
3. Envie os arquivos index.html, .nojekyll e README.txt para a raiz do repositório.
4. Faça Commit changes.
5. No GitHub, abra Settings > Pages.
6. Em Build and deployment, escolha Deploy from a branch.
7. Selecione a branch main e a pasta / (root), depois Save.
8. Aguarde a publicação. O endereço será https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/.

IMPORTANTE: o arquivo principal já está nomeado index.html e fica na raiz do ZIP.
Este pacote publica o HTML enviado; recursos externos do site dependem de conexão com a internet.
